# UI Enhancements Design: The Capture Deck Polish

## Overview
Elevate "The Capture Deck" studio gear aesthetic with hardware-inspired tactile elements, improved queue/history management, and polished micro-interactions.

## 1. Hardware UI Polish & Tactile Elements
- **Mode Rocker:** Redesign Audio/Video mode selector as a physical analog toggle switch.
- **Rack Styling:** Inset container shadows, brushed dark slate card borders, and dynamic amber/cyan perimeter lighting based on active mode.
- **Tabular Data:** Enforce fixed-width numerical rendering in JetBrains Mono for download speed, ETA, and progress metrics to eliminate UI jitter.

## 2. Queue & History Drawer
- **Slide-over Drawer:** Collapsible sidebar/drawer for active queue and past history, avoiding main surface clutter.
- **Batch Actions:** Global controls to clear history, cancel all active jobs, or open download folder.

## 3. Micro-Interactions & Feedback
- **REC LED Indicator:** Pulsing amber/cyan glow ring during active downloads.
- **Waveform Animation:** Real-time animated frequency visualizer during active download progress.
